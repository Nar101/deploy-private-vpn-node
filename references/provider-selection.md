## 使用时机

在 `new-deploy` 或需要购买新 VPS 的 `clone` 模式中完整读取本文件。用户只要求排障、维护或客户端适配时不读取。

本流程的目标不是维护一份会过期的供应商排行榜，而是让每次采购都从当前官方页面重新获得可比较证据。不得在 Skill 中写死套餐现价、库存或促销结论。

## 采购输入

开始调研前确认：

- 用户所在地和实际运营商；
- 目标服务及其支持地区；
- 可接受的月预算范围；
- 可一次支付的总金额；
- 是否接受季付、年付或多年预付；
- 预计月流量和最低带宽；
- 设备数量及是否有极少数受信任用户共享；
- 是否优先国内厂商、人民币付款和中文售后；
- 是否接受数据中心 IP、偶尔换 IP 和购买后实测；
- 当前是否有可用节点作为迁移回退。

用户不懂技术时，提出推荐默认值并解释影响，不把所有字段变成必须先回答的考试。

## 搜索范围

按下列顺序查找，不因发现一个可购买方案而提前停止：

1. 国内云厂商提供的海外地域：优先中文控制台、人民币付款、微信/支付宝和国内售后。
2. 海外主流云厂商：作为价格、流量和带宽基准，并在明显更优时列为备选。
3. 用户明确指定或信任的其他供应商：必须执行相同核验，不因熟人推荐降低标准。

“国内厂商优先”指厂商和购买体验优先，不代表购买中国内地地域。用于访问海外目标服务时，地域仍须满足目标服务支持范围和用户所在地法律及服务条款。

优先读取官方购买页、官方定价页、官方计费文档、官方退款规则和官方服务条款。媒体文章、测评和论坛只能作为线索，不能单独支持价格、续费或退款结论。

## 预算分层

预算不是搜索下限。即使用户可接受更高价格，也继续向低价档查找，并明确低价牺牲项。

| 档位 | 参考月预算 | 主要目标 | 常见代价 |
|---|---:|---|---|
| 极限低价 | 10～20 元 | 找到能完成个人轻量使用的最低成本方案 | 可能要求年付、内存小、流量少、线路普通、仅限首购 |
| 性价比 | 20～40 元 | 平衡独立 IPv4、资源、带宽、流量与可维护性 | 可能使用共享峰值或普通国际线路 |
| 稳妥使用 | 40～80 元 | 更大的带宽与流量、更方便的账号和售后 | 仍不等于独享线路，必须实测 |
| 高保障 | 80 元以上 | 购买更好的线路、SLA 或带宽保障 | 验证溢价是否真实改善用户链路 |

档位只用于组织比较，不是价格承诺。用户预算落在某一档时，仍展示相邻低档和高档中的有效候选，让用户知道节省或加价分别改变了什么。

## 统一比较字段

每个候选至少记录：

- 厂商、产品、地域和可用区；
- 官方来源链接及核对日期；
- CPU、内存、系统盘和操作系统支持；
- 独立公网 IPv4 是否包含、额外费用和换 IP 费用；
- 带宽数值、上下行方向、峰值/保障/独享口径和共享资源池说明；
- 月流量、入站/出站计量方式、超额单价和限速/停机规则；
- 首购总价、购买时长、折算月价和一次需支付金额；
- 续费总价、续费周期和折算月价；
- 自动续费默认状态及价格；
- 新用户、首台、地域、库存、优惠券和活动期限限制；
- 税费、附加服务及客户端等其他成本；
- 退款期限、退款方式、退款去向和销毁影响；
- 目标服务地区支持、数据中心 IP 属性和服务条款风险；
- 月付、按小时、试用、销毁和回退能力；
- 当前证据等级：官方购买页、官方文档或真实测试。

任一关键字段缺失时标记“未确认”，不得凭经验补全。

## 价格换算与优惠核验

统一计算：

```text
首购折算月价 = 首次实际支付总额 ÷ 首购月数
续费折算月价 = 当前官方续费总额 ÷ 续费月数
首年实际成本 = 首年内所有必须支付项目之和
```

同时展示“折算月价”和“一次需支付金额”。例如宣传为 10 元/月但必须一次支付 360 元三年，不能只显示 10 元。

逐项核对：

1. 当前价格是长期标准价、限时活动价、首购价还是券后价；
2. 是否仅限新用户、首台实例、特定地域、特定镜像或特定付款周期；
3. 续费是否同价，官方页面是否只写“以续费页面为准”；
4. 自动续费是否默认开启，自动续费使用标准价还是活动价；
5. 独立 IPv4、系统盘、备份、流量、税费或安全产品是否另计；
6. 退款退回原支付渠道还是云账户余额，优惠券和折扣是否退回。

无法在官方页面确认续费价时，写“续费价未确认”，并降低推荐置信度。不得用首购折算价推测续费成本。

## 网络与流量口径

带宽必须区分：

- 峰值带宽：允许达到的上限，不承诺持续达到；
- 共享资源池峰值：服务器和 IP 独立，但底层出口容量由多个云实例竞争；
- 保障带宽或独享带宽：有明确承诺或预留，通常价格显著更高；
- 端口速率：物理或虚拟端口上限，不等于用户所在地到机房的真实速度。

流量必须区分：

- 不限流量：套餐内不按 GB 额外收费，但仍受带宽、资源、服务条款和异常使用审查约束；
- 固定流量包：确认额度、重置日期、只计出站还是双向计量；
- 超额计费：确认单价、扣费账户、欠费或限速规则；
- 公网流量与用户手机套餐流量是两套账，不能混为一谈。

不得用距离替代线路证据。地区近通常降低延迟，但普通国际线路仍可能在中国大陆晚高峰出现抖动、丢包或低吞吐。购买页参数只能证明能力上限，不能证明深圳移动、联通和电信的真实表现。

## 硬门槛与推荐顺序

先淘汰不满足硬门槛的方案，再比较价格：

1. 地域受到目标服务支持，且使用目的符合适用法律与服务条款；
2. 包含或可购买独立公网 IPv4；
3. 支持 Ubuntu 22.04/24.04 LTS 和 SSH 密钥；
4. 预算、一次支付金额和付款周期可接受；
5. 流量、带宽和资源满足最低使用要求；
6. 存在可执行的购买后验收和失败回退方式。

满足硬门槛后按用户目标排序：

1. 当前独立 IP 和目标服务可访问性；
2. 用户实际运营商的稳定性、丢包和晚高峰吞吐；
3. 长期续费总成本；
4. 流量和实际可用带宽；
5. 月付、退款、换 IP 和销毁便利性；
6. 中文控制台、人民币付款、售后和维护体验。

数据中心 IP 不等于住宅 IP，也不能在购买前保证永久干净。把“独立 IP”“当前可访问”“历史信誉良好”分别验证和陈述。

## 调研和付款流程

1. 从用户输入生成统一筛选条件。
2. 查完国内厂商海外地域，再查海外基准供应商。
3. 至少产出三个满足硬门槛的候选；不足时列出已查范围和淘汰原因。
4. 分别标记“最便宜但可用”“综合性价比最高”“稳定性优先”。
5. 给出结合用户约束的一个主推荐和一个回退方案。
6. 在进入购买页前报告所有已确认成本和未确认项。
7. 在最终付款前再次回读：买什么、地域与规格、首付金额、周期、续费价、自动续费状态、退款窗口和数据销毁风险。
8. 付款、实名、验证码、密钥下载和最终下单由用户本人完成。
9. 购买后不立即替换当前连接；独立部署并完成出口、目标服务、真实下载和多运营商晚高峰验收。
10. 在退款窗口内决定保留、退还或回退；不因已经花费部署时间而保留不合格实例。
